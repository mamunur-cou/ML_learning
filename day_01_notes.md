## Today I learned:
- Gradient Descent is an optimization algorithm used to minimize a loss function.
- Formula: θ = θ - α * ∇J(θ)
  - θ (theta) = parameter
  - α (alpha) = learning rate
  - ∇J(θ) = gradient of the loss function

## My Understanding:
Gradient Descent works by iteratively moving the parameters in the opposite direction of the gradient to find the minimum of the loss function.
